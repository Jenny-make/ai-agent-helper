# Changelog

本文档用于记录项目阶段进展、当前版本定位与后续版本计划。

---

## Unreleased

当前分支处于未发布开发阶段，建议版本定位：

`0.1.0-SNAPSHOT`

### 已完成

- 增加多模型接入能力：
  - `DeepSeek`
  - `MiniMax`
  - `OpenAI-compatible`
- 增加控制台问答入口，支持本地直接输入问题进行验证
- 增加 `app.ai.provider` 路由逻辑
- 增加 Spring AI 自动配置排除逻辑，避免未使用 provider 影响启动
- 增加会话记忆能力：
  - 最近轮次保留
  - 历史摘要压缩
  - 追问消歧辅助
- 增加回答文本策略能力：
  - 语言跟随最新用户消息
  - 上下文相关追问识别
  - 语言切换重写
  - prompt 泄漏 / 元响应兜底清洗
- 增加可选 RAG 检索入口与配置项
- 增加飞书知识同步第一版：
  - 支持按 `docx` token 拉取飞书文档纯文本
  - 支持按飞书文件夹链接自动发现并递归展开其中的 `docx`
  - 本地切片后写入 Milvus / VectorStore
  - 本地状态文件记录上次 chunk ids，便于重复同步时先删后写
  - 管理接口支持手动触发同步
- 增加飞书基础消息闭环：
  - `url_verification`
  - `im.message.receive_v1` 文本消息解析
  - 群聊 `@` 识别与消息清洗
  - 重复投递去重
  - 调用飞书 Open API 回发文本消息
- 增加飞书租户访问令牌获取与缓存
- 增加向量库健康检查接口
- 增加 MiniMax 运行配置模板与控制台 / 飞书调试说明
- 增加单元测试，覆盖飞书消息过滤与去重、会话记忆、文本策略等核心路径

### 当前限制

- 飞书仍未完成加密事件解密与更严格的签名校验
- 当前仅支持飞书文本消息，不支持图片、文件、卡片等消息类型
- Milvus 仅完成检索骨架，未完成文档导入与 embedding 入库链路
- 会话记忆当前为进程内内存实现，重启后不会保留，也未支持多实例共享
- 暂无转人工、工单、审计日志等企业客服能力
- 部分历史文档存在编码遗留问题，后续需逐步清理

### 当前推荐定位

当前版本推荐对外理解为：

**飞书客服问答 MVP / 可本地与飞书双入口验证的第一版客服基座**
