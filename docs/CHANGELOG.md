# Changelog

本文档用于记录项目阶段进展、当前版本定位与后续版本计划。

---

## Unreleased

当前分支处于未发布开发阶段，建议版本定位：

`0.1.0-SNAPSHOT`

### 已完成

- 增加多模型接入骨架：
  - `DeepSeek`
  - `MiniMax`
  - `OpenAI-compatible`
- 增加控制台问答入口，支持本地直接输入问题进行验证
- 增加 `app.ai.provider` 路由逻辑
- 增加 Spring AI 自动配置排除逻辑，避免未使用 provider 影响启动
- 增加 RAG 检索骨架与配置项
- 增加基础飞书 Webhook 占位入口
- 增加 MiniMax 运行配置模板与控制台调试说明

### 当前限制

- 飞书接入仍是占位版本，未完成真实验签与消息回发
- Milvus 仅完成检索骨架，未完成文档导入与 embedding 入库链路
- 暂无转人工、工单、会话管理能力
- 部分历史文档存在编码遗留问题，后续需逐步清理

### 当前推荐定位

当前版本推荐对外理解为：

**企业客服 Agent 基座 / 本地可验证的第一版问答原型**
